 4. Material Components for Android and AndroidX
================================================================================

    The native widget layer is Material Components for Android and the AndroidX
    libraries, consumed as their .NET binding packages
    (Xamarin.Google.Android.Material, Xamarin.AndroidX.*), which carry their own
    license and notice files (MIT for the bindings, Apache License, Version 2.0
    for the Java libraries). No source from them is included in this
    repository.

    The add-in packages likewise reference, without incorporating their source,
    SkiaSharp and HarfBuzzSharp (MIT), AndroidX Media3 and AndroidX WebKit
    (.NET bindings: MIT; Java libraries: Apache License, Version 2.0) and the
    self-produced CodeBrix packages the add-ins build on (CodeBrix.SkiaSvg,
    CodeBrix.Sqlite, CodeBrix.Platform.OpenGL, CodeBrix.Terminal,
    CodeBrix.Plotter, CodeBrix.VideoPlayback, CodeBrix.Audio.Android and the
    CodeBrix.Platform RobotoMono font package); each carries its own license
    and notice files.
